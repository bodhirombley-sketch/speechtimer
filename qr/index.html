QR Code Generator

Voer een URL in om direct een QR-code te genereren.

Vul een URL in...

Hoe werkt de QR Code Generator?

Typ of plak een link (of een stukje tekst) en je krijgt direct een QR-code die je kunt downloaden als afbeelding. Scan hem met de camera van je telefoon om de link te openen.

Zo gebruik je de tool

  1. Vul een link of tekst in.
  2. De QR-code verschijnt direct in beeld.
  3. Download de afbeelding en gebruik hem op een poster, flyer, sticker of in een presentatie.

Wanneer is dit handig?

Voor een link naar je website op een poster, een wifi-gegevenstekst op een kaartje, een contactpagina op een visitekaartje of een sticker met een link.

Goed om te weten

De code bevat precies wat je invult en verloopt nooit, maar werkt alleen zolang de link zelf werkt. Test hem altijd met je telefoon voordat je gaat printen. Houd de code groot genoeg en met voldoende wit eromheen.

Privacy

Let op: de QR-code wordt gemaakt door de externe dienst api.qrserver.com. De link of tekst die je invult wordt daarheen gestuurd. Zet er dus geen gevoelige gegevens in.

Veelgestelde vragen

Verloopt de QR-code?

Nee. De code bevat de link zelf en blijft werken zolang de link werkt.

Kan ik ook gewone tekst gebruiken?

Ja, je kunt elke tekst invullen, niet alleen links.

Is het gratis?

Ja, zonder account en zonder watermerk.
